Decorator Attributes
====================
Decorator attributes draw additional GUI around a field, instead of replacing the way the field itself is drawn.

.. note::
    Unlike :ref:`label-drawer-attributes`, a ``field`` can have more than one decorator attribute,
    and can be combined with a drawer attribute.
